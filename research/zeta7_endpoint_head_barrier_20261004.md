# ζ(7)端点法的头块障碍与实际收益分解

日期：2026-10-04。承接[端点充分判据](zeta7_endpoint_budget_20261004.md)。原判据成立；这里证明它的统一上界受头块本原值约束，因此需要重新安排研究优先级。尚未证明ζ(7)无理；以下一般论证未Lean形式化。

## 1. 统一上界继承头块的小值要求

设有理对称矩阵关于X仿射，参数y只修正尾部二阶块

\[
\begin{pmatrix}0&1\\1&-\beta\end{pmatrix}.
\]

写完整行列式为

\[
\Delta(X,y)=f_0(X)+f_1(X)y-T(X)y^2,
\qquad T(X)=\det T_X,
\]

其中T_X是与y无关的头块。令ξ处头块正定，尾部Schur参数满足a>0、R>0；完整正定区间是(c−R,c+R)。算术参数为y=α+Lk，L>0。令c_*是代入后全部X、k系数的共同正有理content，c_T是T(X)的content，P_T=T/c_T。

**头块障碍。** 有

\[
M=\frac{L^2c_T}{c_*}\in\mathbb Z_{>0},\qquad
U=\frac{2RL\det T_\xi}{c_*}
=\frac{2R}{L}\,M\,P_T(\xi).
\tag{1}
\]

因此在端点引理的条件2R>L下，恒有

\[
\boxed{U>P_T(\xi)>0.}
\tag{2}
\]

证明：k²系数是−L²T(X)。全部系数除以c_*后都是整数，所以这一个系数多项式的content恰为正整数M。再代入T(ξ)=c_TP_T(ξ)，得到(1)与(2)。这是完整content的恒等式，不依赖小素数截断。

若一列统一U有负K²指数，则头块P_T也已经有负K²指数。这里还须核对次数：当某个有理y使G_ξ(y)严格正定时，对称仿射铅笔的行列式次数等于其X斜率矩阵的秩。证明是用G_ξ(y)的正定平方根把铅笔化为I+(X−ξ)B，再用实对称B的特征值分解。头块斜率的秩不超过全矩阵斜率的秩，因此deg P_T≤deg_XΔ。故若后者为O(K)，头块本身已足以完成通常的有理分母矛盾。

这不排除某个特选参数优于头块。它限制的是不追踪参数额外content、只使用共同c_*的统一端点上界。

## 2. 特选参数真正需要的两个收益

对正定候选y，取它到较近端点的距离0<δ≤R，令

\[
J(k)=\operatorname{cont}\Delta(X,\alpha+Lk)/c_*
\in\mathbb Z_{>0}.
\]

实际本原值满足精确分解

\[
\boxed{\frac{P_k(\xi)}{P_T(\xi)}
=M\frac{2R}{L}\frac{\delta}{L}
\left(1-\frac{\delta}{2R}\right)\frac1{J(k)}.}
\tag{3}
\]

最近余类端点的δ≤L给出原充分上界；但真正超越头块需要额外J(k)和特别小的δ/L共同压过M·2R/L。单独使R/L变大，不能绕过(1)中的算术约束。

原九组固定x的18个端点全部核验(1)与(3)，全部实际值也高于各自的头块。原1396.412候选的预算为：

| 项 | 严格计算的对数（此处四舍五入） |
|---|---:|
| 头块本原值P_T | 1319.845745 |
| 统一U/P_T | 83.618691 |
| 额外J=1040 | 6.946976 |
| δ/L | −0.105296 |
| 1−δ/(2R) | 约−3.9×10⁻²⁸ |

这解释了实侧端点收益已出现而本原预算仍不够的原因。[精确程序](zeta7_endpoint_head_barrier_20261004.py)与[九组完整证书](zeta7_endpoint_head_barrier_20261004.json)保存完整有理content、输入哈希和Arb区间。

## 3. 改用统一整数值content至多补一个因子2

有人可能把c_*换成所有整数k取值的共同content。将全部系数除以c_*，记整数二次系数向量F(k)=A+Bk+Ck²，其全部系数gcd为1。全部整数取值的共同gcd恰为

\[
\gcd(A,\ B+C,\ 2C),
\]

这里gcd跨越所有X系数。因为F(0)、F(1)、F(2)给出该gcd，反向由F(k)=A+(B+C)k+2C\binom{k}{2}证明。该gcd只能是1或2：奇素数将同时整除A、B、C；若4整除该gcd，则全部A、B、C至少有公因子2，均与本原性矛盾。因此这种统一整数值优化只改变常数因子，不能提供新的负K²指数。

这不约束特选k的J(k)，它可能大得多。对一个固定余类，已经完成[所有整数参数的额外content分类和全局优化](zeta7_endpoint_coset_optimum_20261004.md)。跨尺度的三个原始头块与尾部端点比较见[三尺度报告](zeta7_endpoint_scaling_20261004.md)。后续应研究可控制的特选J(k)、端点逼近，或直接改善头块构造。
