# 全部奇数 ζ 与 Catalan：统一理论入口及下一阶段研究方案

日期：2026-10-04。承接本项目 ζ(5) 已验证基线和 ζ(7) 研究审计；本轮暂停具体参数搜索，扩大原始文献范围。**本轮没有得到 ζ(7)、Catalan 或 3ζ(3)+ζ(5) 的新无理性证明。**

后续进展：[统一框架的桥梁研究](odd_zeta_bridge_progress_20261004.md)已给出全族正积分障碍、纯G芽的实际四维函数独立／最小阶数4、真实前缀分母下界及整投影费用；这些是已证明的中间命题，仍未闭合指定值无理性判据。本文保留上一阶段总体判断。

核心判断：**统一对象已存在，但能无条件一次解决全部目标的定理尚未取得。** 最深的统一路线是 cyclotomic 混合 Tate / Artin–Tate 周期；最值得近期推进的证明路线，是将其特征投影与真实整模型，连接到算术 holonomy 的函数秩判据。纯动机结构解释应寻找什么对象；holonomy 尝试把该对象转成数值上的有理性矛盾。这个连接仍需新数学，不能当成现成工具装配。

## 1. 先看统一性：同一 polylog 的不同分量

令 β(s)=L(s,χ₋₄)，G=β(2)。按级数直接分拆得到

\[
\operatorname{Li}_s(i)
=-2^{-s}(1-2^{1-s})\zeta(s)+i\beta(s),\qquad s\ge2.
\]

| 权重 | 已知纯 Tate 分量 | 困难的扩张分量 |
|---|---|---|
| 奇数 s≥3 | β(s)是非零有理数乘πˢ | ζ(s) |
| 偶数 s≥2 | ζ(s)是非零有理数乘πˢ | β(s)，包含G |

更一般的真实目标是 χ(−1)=(−1)^{s+1} 的实 Dirichlet L(s,χ)：与Euler/Bernoulli公式的匹配奇偶正好相反。对本原特征，由Gauss和投影将它写成单位根处 Li_s 的代数组合。固定s的这些函数满足有理微分系统；改变s或导子改变其层级，而不是改变问题的基本类型。详见 [Dirichlet专题及公式推导](odd_zeta_global_dirichlet_20261004.md)。

这不意味着任意导子都具有level 4同样的类别生成定理。**当前统一全部奇ζ和偶β，只需先研究四次单位根。** 基础类别为 MT(Z[i,1/2])，并保留复嵌入和Artin特征。Catalan的Q上模型不应简单称作mixed Tate；扩到Q(i)后才有相应结构。[Deligne2010](https://www.numdam.org/article/PMIHES_2010__112__101_0.pdf)，[Eskandari–Murty–Nemoto最新v3](https://arxiv.org/abs/2510.20648v3)。

## 2. 研究全景：已有统一结论的量词离目标多远

| 路线 | 实际取得的结果 | 距离“每一个指定值” |
|---|---|---|
| Apéry、ζ(5)本项目基线 | 指定值无理 | 每个新权仍需新输入 |
| Ball–Rivoal及后续维数改进 | 一族值与1的Q张成空间维数增长 | 不指定ζ(7)，也不指定3:1组合 |
| FSZ、Lai等计数方法 | 无理值个数的强下界 | 个数不等于线性无关维数 |
| Lai–Zhou偶β有限集合 | β(2),…,β(10)中至少一个无理 | 不指定G |
| Brown、Dupont的模空间/动机积分 | 包含经典构造、解释允许权和奇偶消元 | 动机纯性不提供足够整性和衰减 |
| Zudilin行列式、Hankel正矩 | 一般的单目标充分判据已存在 | 缺逐权满足判据的输入存在定理 |
| CDT算术holonomy | 指定的L(2,χ₋₃)等实例成功 | ζ(7)和G的完整秩—分母—容量余量尚未得出 |
| 周期猜想 | 条件性统一超越/独立性 | 核心数值单射未证明 |

具体定理、版本和量词见 [逼近专题](odd_zeta_global_approximation_20261004.md) 与 [Dirichlet专题](odd_zeta_global_dirichlet_20261004.md)。尤其，Lai最新2026-09-25稿的正文把维数常数1.009列为Theorem，把计算强化1.119356等列为Claim；不能只读摘要。Fischler的平方根量级结果是**维数**，Lai2025的平方根量级结果是**个数**。[Lai2026v3](https://arxiv.org/abs/2407.14236v3)，[Fischler](https://arxiv.org/abs/2109.10136v3)，[Lai2025](https://arxiv.org/abs/2501.05321v2)。

Zudilin2017已有单目标正矩行列式判据。因此ζ(5)论文的重要新输入，应定位于适合具体目标的泛函、兼容算术与实侧估计，而非“首次发明通用行列式无理性判据”。[原文Prop.2](https://arxiv.org/abs/1507.05697v2)。

## 3. 最深的路线：周期猜想确实能一次覆盖目标

Brown/Deligne体系中，奇ζ和偶β对应不同权的非平凡扩张坐标，其自由结构与regulator方向已经有无条件定理。Deligne2010 Conjecture5.6要求level4的**数值比较周期点泛型**。将它与原文坐标结构结合，可条件性推出

\[
\pi,\log2,\zeta(3),\zeta(5),\ldots,\beta(2),\beta(4),\ldots
\]

的联合代数独立；“无限集合”指每个有限子集。推导和系数域处理见 [动机专题§3](odd_zeta_global_motives_20261004.md)。这会解决比无理性强得多的问题，但猜想仍未证明；以猜想为假设不能成为本项目的新证明。[Deligne Conj.5.6与Appendix A.2](https://www.numdam.org/article/PMIHES_2010__112__101_0.pdf)。

需要跨越的缺口不是“非零”：一个非零实格子的生成元可以是有理数。Hodge扩张非平凡排除的是模Tate周期的消失，也不排除所有有理实代表。把数值等式按权拆开，或对数字直接施加motivic导子，同样需要先证明数值周期映射的核具有相应性质。

可以提出两种较弱、明确的新定理靶点：

- **有限深度一线性单射**：对每个有限S，周期映射在 Q·1⊕Σₙ∈S Q·aₙᵐ 上单射，其中aₙ取奇ζ或偶β目标。这足以同时推出全部无理，还会解决3ζ(3)+ζ(5)这样的固定非零组合。
- **逐秩二扩张的比较点定理**：对每个目标周期αₙ，证明 trdeg_Qbar Qbar(2πi,αₙ)=2。这足以逐个证明超越，却不要求不同权目标联合代数独立。

它们比整个周期猜想弱，但仍接近未解问题本身；本轮的价值在于明确欠缺的命题，而非给结论改名。Huber–Wüstholz的1-periods定理提供严谨的低阶模型；高权Tate扩张超出1-motive的Hodge型，不能直接套用。[专题§5](odd_zeta_global_motives_20261004.md)，[原著v8](https://arxiv.org/abs/1805.10104v8)。

## 4. 最值得近期转向：真实周期投影 + 算术holonomy

CDT已经证明1、ζ(2)、L(2,χ₋₃)线性无关，给“同一困难奇偶结构的指定L值”提供了真正新实例。其方法不是只要求一个整数逼近足够小，而是用算术斜率与解析容量限制函数空间维数：假设目标有理会产生更多有理系数、可亚纯延拓的解；若其独立秩超过分母允许的上界，就矛盾。[2024长文v2](https://arxiv.org/abs/2408.15403v2)，[2025框架稿](https://arxiv.org/abs/2510.04156v1)。

**本文的研究判断：**这条路线最可能把现有项目从固定Gram的局部调优推进到结构层面，但不能保证成功。将动机特征投影与它结合，至少有三个真实新问题：

1. 有理动机投影能否实现为**实际**子商周期和边界消元，而不是形式环里令π²等于零？
2. 该子商的整Betti/de Rham模型，能否给出完整分母filtration？投影所需的大分母和坏素数必须保留。
3. 随权增长，独立函数秩的增益能否超过分母与解析容量的代价？

Catalan已有具体警示：CDT实侧所讨论的D解在所选原点奇异，还含 G 与π²两个周期，2-adic侧却没有同样的Tate项。把后者的成功直接搬到实侧会丢失正则芽及完整周期所需的输入。原文对两个既有Catalan家族的失败分析是特定家族的门槛障碍，不是所有holonomy路线的不可行定理。详见 [holonomy专题](odd_zeta_global_holonomy_20261004.md)。

模形式、Eichler积分、Eisenstein上同调可以帮助制造解析延拓和字符投影，但Ramanujan奇ζ变换含其他级数/周期，不自动成为Euler型公式。[Berndt–Straub](https://arxiv.org/abs/1701.02964v1)。近期G-function与unlikely intersections理论控制特殊关系发生的参数，也没有自动排除指定代数点处的全部周期关系。[André综述](https://ems.press/journals/rlm/articles/14299473)。

## 5. 保留统一充分判据，但改变寻找输入的方式

设η为指定实目标。若存在整数多项式P_j，d_j=deg P_j≥1，且

\[
0<|P_j(\eta)|,\qquad
\frac{-\log|P_j(\eta)|}{d_j}\longrightarrow+\infty,
\]

则η无理。证明：若η=u/v，则非零整数v^{d_j}P_j(u/v)给出 |P_j(η)|≥v^{-d_j}，与上式矛盾。次数固定为1时，非零整数线性形式趋零已足够。

当前K阶行列式、次数O(K)、负K²指数只是实现此原则的一种方式。更换到几何局部系统或holonomy不必保留同一参数化。对多项式路线，缺的是同时保证**纯目标、非零、完整content和净衰减**的逐权构造定理；对holonomy路线，缺的是完整函数系统的正秩余量定理。二者可以互相启发，不能互相免除假设。

若Q_j∈Q[X]、c_j为其全部系数的正有理content，则P_j=Q_j/c_j。所有换基、Gamma归一化、分母与实估计必须作用于同一个Q_j；只取某个漂亮的实上界，或只取另一个形式的整除性，都不能连接这个判据。

## 6. 下一阶段可交付的数学工作

| 顺序 | 对象和目的 | 完成标准 |
|---|---|---|
| 1 | level4深度一统一正常形，含奇ζ、偶β、Tate与Artin部分 | 对每权写出真实周期坐标、允许投影和禁止的形式删项 |
| 2 | 校准CDT χ₋₃权2成功实例 | 用同一数据重建坏分支、独立秩、分母staircase及严格余量 |
| 3 | ζ(7)与G的完整周期包 | 给出最小微分系统和整模型；查明其他周期为何出现、是否可实际消去 |
| 4 | 跨权的结构存在命题 | 精确陈述何种投影/局部系统给正余量；证明或给出适用范围障碍 |
| 5 | 只对已成立的无限命题安排形式化 | 不用有限实验替代跨尺度渐近或数值核稳定性 |

可并行保留(L1)/(R2)高权周期湮灭子路线；它更接近统一超越定理，但现有低权技术不能直接外推。近期判断依据应是上述中间命题的成立范围，而非一次参数搜索是否找到小数值。
