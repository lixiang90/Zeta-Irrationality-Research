# ζ(3)、ζ(5) 的线性无关性：混合矩行列式路线

日期：2026-10-02。以本文件夹中已经给出的 ζ(5) 无理性定理及形式化为已知前提。本记录中的混合矩推导尚未形式化；有限计算不是渐近整除性证明，也没有证明新的线性无关性结论。

## 1. 两个不同目标

记 α=ζ(3)、β=ζ(5)。分别知道 α、β 无理，不能推出它们在 Q 上线性无关，例如 √2 与 2√2。

- α、β 在 Q 上线性无关，等价于 β/α 无理。
- 每个非零有理系数对 (a,b) 都满足 aα+bβ 无理，等价于 1、α、β 在 Q 上线性无关。

第二个目标严格更强：√2 与 1+√2 线性无关，但两者之差为有理数。由于乘非零有理数不改变无理性，只需研究互素整数方向 (a,b)。坐标轴方向已由单独无理性解决。

不能把假设 β=rα+s 直接代入现有 ζ(5) 小整数多项式，然后凭 α 无理得出矛盾：无理性本身不提供这些高次整数多项式在 α 处的下界。

## 2. 一个足够的多项式判据

对每个固定方向 (a,b)，若能构造 P_n∈Z[X]，满足

    deg P_n ≤ C_{a,b} n,
    0 < |P_n(aα+bβ)| ≤ exp(−c_{a,b} n²),  c_{a,b}>0,

则 aα+bβ 无理。因为若其等于 p/q，非零值至少为 q^(−deg P_n)，与上述上界矛盾。

这里不需要常数对所有方向统一，也不需要先显式计算每个 P_n。存在性证明足够，但必须同时保证整数系数、非零值和量级。

## 3. 将两个 ζ 值对齐成一个未知量

令 t=y²，定义正矩泛函

    μ_s(f)=∫₀∞ f(y²) w_s(y)dy,
    w₃(y)=(2π)² y³ Σ_{ℓ≥1} ℓ² exp(−2πℓy),
    w₅(y)=(2π)⁴ y⁵/12 Σ_{ℓ≥1} ℓ⁴ exp(−2πℓy).

其多项式矩为

    μ₃(t^k)=(-1)^k (2k+3) B_{2k+2}/2,
    μ₅(t^k)=(-1)^k (2k+3)(2k+4)(2k+5) B_{2k+2}/24.

这由逐项 Gamma 积分及偶数 ζ 值公式得到。所有这些矩均为有理数。对正整数 j，极点矩为

    μ₃(1/(t+j²))=j² ζ(3,j)−1/(2j)−1/2,
    μ₅(1/(t+j²))=j⁴ ζ(5,j)−1/(2j)−1/4.

ζ(3) 公式可以由 Hermite 公式及两次分部积分推出。具体地，设 F(y)=1/(exp(2πy)−1)、g(y)=y³/(y²+j²)，则 w₃=y³F''，边界项消失，并且

    g''(y)=2j²y(3j²−y²)/(j²+y²)³.

Hermite 公式在 s=3 时的积分项恰为上式积分除以 j²。公式中的 ζ(s,j) 是 Hurwitz ζ 函数。

直接相加 μ₃、μ₅ 会出现 j² 与 j⁴ 不匹配。改用

    ν_{a,b}(f)=b μ₅(f)−a μ₃(tf)

后，由 t/(t+j²)=1−j²/(t+j²)，得到

    ν_{a,b}(1/(t+j²))=j⁴ X+r_j(a,b),
    X=aζ(3)+bζ(5),
    r_j=−j⁴(a H_{j−1}^{(3)}+b H_{j−1}^{(5)})
        −a(j²/2+j/2+1/4)−b(1/(2j)+1/4).

因此 r_j 为有理数，且 ν 的多项式矩也为有理数。部分分式展开使整个构造只含一个未知量 X。

## 4. 保留原行列式的次数和部分正性

使用原参数 K=40n、N=3n、h=37n，D_m(t)=∏_{j=1}^m(t+j²)、W=D_N^6，定义

    G_{a,b}(X)_{i,j}=ν_{a,b}(t^(i+j) W/D_K),  0≤i,j<h,
    Δ_{a,b}(X)=det G_{a,b}(X).

右边理解为上一节恒等式定义的仿射形式。它的 X 系数矩阵与原 ζ(5) 构造完全相同。故最高次系数仍是原来的非零加权 Vandermonde 行列式，deg Δ=h。清除有理系数的分母并约去整数公因子，总能得到本原整数多项式；困难在于这种归一化对数值大小的影响。

混合权重为 w_{a,b}=b w₅−a y²w₃。令 q=exp(−2πy)，精确计算得到

    w₅/(y²w₃)=(π²/3)(1+10q+q²)/(1−q)²
              =(π²/3)(1+12q/(1−q)²).

这个比值随 y 从 0 增至 ∞，由 ∞ 严格递减到 π²/3。

整体变号后可设 b>0。若 a/b<π²/3，则存在仅依赖 (a,b) 的正数 c、C，使

    c w₅≤w_{a,b}≤C w₅.

例如 a≥0 时可取 c=b−3a/π²、C=b；a<0 时可取 c=b、C=b+3|a|/π²。因 W/D_K 在正实轴为正，Gram 矩阵严格正定，且

    c^h Δ_{0,1}(ζ(5))
       ≤ Δ_{a,b}(aζ(3)+bζ(5))
       ≤ C^h Δ_{0,1}(ζ(5)).

这是正定矩阵序与行列式的直接结果。因 h=O(K)，固定方向的额外对数代价只有 O(K)。所以乘上原来的公共实侧尺度因子 S_K 后，K² 主阶分析估计可以迁移。

若 a/b>π²/3，权重恰变号一次；这时上述正定性证明不可用。有限阶行列式仍可能为正，但不能据此推断所有阶非零。

对仅要求 ζ(3)、ζ(5) 线性无关的目标，潜在零关系必定异号。于是它们全部落在上面的正权重区域。换言之，该较弱目标在本路线中没有新的权重变号障碍，仍需解决算术估计。

## 5. 精确首项实验：算术损失不能忽略

脚本 `zeta35_mixed_moments.py` 复用原 `Zeta5-mo271/scripts/hankel.py`，在 n=1、K=40、h=37 上计算有理行列式多项式及其本原整数形式 P。结果如下（自然对数，显示近似中值）：

| a | b | log abs(P(aζ(3)+bζ(5))) |
|---:|---:|---:|
| 0 | 1 | −265.129067 |
| −1 | 1 | 133.080649 |
| 1 | 1 | 104.166219 |
| 3 | 1 | 34.699288 |
| 4 | 1 | 65.171112 |

前四行均有全局正权重；第五行的正性只在这个有限阶数得到区间计算验证。每个多项式由精确有理矩阵及特征多项式计算，另在 X=−1、0、1、2、1/2 五点直接计算行列式进行一致性检查。实际 ζ 值处用 Arb 区间运算，五个区间均严格为正。完整系数、内容因子与区间保存在同名 JSON 中。

这些结果只涉及 n=1。它们没有证明任一方向渐近失败，也没有证明新方向无理；它们说明原 ζ(5) 方向的巨大算术优势不能直接假定对混合方向保持。

若 Δ=c_n P，其中 c_n>0 为有理内容，则

    log |P(X)| = log |Δ(X)| − log c_n.

实侧比较控制第一项；真正待证的是第二项不能吃掉 K² 量级的衰减。这与此前 ζ(7) 研究中的“正性容易保留、整数化代价难控制”是同一类问题。

## 6. 下一步可检验的算术任务

研究三元齐次多项式

    H_n(a,b,X)=det(b A₅−a A_{3,t}+XB),

其中 A₅、A_{3,t} 是有理常数矩阵，B 是原 X 系数矩阵。H_n 总次数 h。对每个素数，估计其全部三元系数的最小 p 赋值，可得到所有整数方向共有的内容下界；也可固定方向获得更强下界。原 ζ(5) 定理只控制 a=0 的特化，不能自动控制整个 H_n。

优先任务：

1. 先研究 a<0、b>0 的正权重区域，特别是 a=−1、b=1，定位相对于纯 ζ(5) 丢失整除性的素数范围及混合子式。
2. 按原证明的局部剩余类方法分析两个矩泛函共同作用后的秩亏，允许调整 W、N/K 以及整值多项式基。
3. 证明“归一化后的 K² 分母增长常数 + 实侧 K² 上界常数 <0”。有限数值改进只能为这个严格不等式找候选。
4. 若能覆盖所有异号有理方向，即推出 ζ(5)/ζ(3) 无理，进而证明两个 ζ 值线性无关。
5. 若要证明所有非零组合无理，还需覆盖 a/b>π²/3 的方向，另证非零性，或者使用下面的共同逼近路线。

对所有有理方向的结论允许逐方向证明，无须强求统一分母界。但只证明 ζ(5)−ζ(3) 无理，仍不足以排除其他有理比例。

还有一个应优先利用的弱化：只证明两个 ζ 值线性无关时，反设目标值 X=0。因此算术上只需控制 H_n(a,b,0) 这一有理数的归一化，不必控制整个 X 多项式的全部系数。更具体地，若能给出正有理乘子 m_n，使 m_n S_K H_n(a,b,0) 为整数，而 log m_n 的 K² 上界小于实侧衰减常数，则正性和小量直接矛盾。这仍需要实质性的算术界，但要求比完整的一元整数多项式构造更弱。对一般组合无理性的目标，未知有理值可能是任何 p/q，不能直接采用 X=0 的弱化。

## 7. 不依赖逐方向正性的另一充分判据

若有整数三元组 (q_n,p_n,r_n)，满足

    q_n α−p_n→0,   q_n β−r_n→0,

且每个尾段的这些三元组都张成 Q³，则 1、α、β 线性无关。

证明：若 u+vα+wβ=0，u,v,w 为不全零整数，则整数

    u q_n+v p_n+w r_n
      =−v(q_nα−p_n)−w(q_nβ−r_n)→0

最终为零。于是整个尾段落在固定有理平面内，与满秩矛盾。

这是完整的条件判据，不是目前已经构造成功的序列。分别拿 ζ(3) 和 ζ(5) 的逼近并乘成共同分母，可能使误差不再趋零，不能跳过这一难点。Brown–Zudilin 的共同有理逼近工作提供可研究的实际构造，但其存在本身不代表满足上述误差与尾段秩条件。

## 9. 具体系数方向的已证范围与“至多一条例外射线”

补充日期：2026-10-02。这里的“已证范围”指本工程已核对的完整证明，不把文献检索未发现某结果当作该结果不存在的证明。

现有 ζ(3)、ζ(5) 无理性定理直接给出全部坐标轴方向：a≠0、b=0，或者 a=0、b≠0。对于上一轮实验中的 (−1,1)、(1,1)、(3,1)、(4,1)，本工程尚未给出其对应组合无理性的完整证明。正权重区域不是已证无理性区域。

但是，以下整体结论现在就有完整的初等证明。

**命题。** 任取 m 个非零有理系数对 (a_i,b_i)，假定它们两两不成比例。则至少 m−1 个数 a_i α+b_i β 无理。

**证明。** 若两个组合 x=aα+bβ、y=cα+dβ 都为有理数，而 ad−bc≠0，则

    α=(d x−b y)/(ad−bc),
    β=(a y−c x)/(ad−bc)

都为有理数，与 α 无理矛盾。故至多一个组合为有理数。证毕。

等价地，E={(a,b)∈Q² : aα+bβ∈Q} 是 Q 线性子空间，而且 dim_Q E≤1。由于 α、β 分别无理，E 的任何非零方向都不是坐标轴。因此非零有理系数的射影空间中，至多一条方向例外；并不是说 Q² 中至多一个系数对例外，因其所有有理倍数会同时例外。

将 b≠0 的方向规范化为 θ_r=β+rα，r∈Q，则至多一个有理数 r_* 使 θ_{r_*} 有理，而且 r_*≠0。直接证明更短：若 θ_r、θ_s 都有理且 r≠s，则 (r−s)α=θ_r−θ_s 有理，矛盾。

具体可得：

- β−α 与 β+α 中至少一个无理；
- β−α、β+α、β+3α 中至少两个无理；
- β+α、β+2α、…、β+100α 中至少 99 个无理。

这些是无条件结论，但不能指定其中哪一个是可能的例外。它们仅需 α 无理，故不是新发现的深层 ζ 算术定理。

为什么仅凭两个数分别无理，不能选出任意预先指定的混合方向？对任何固定 ab≠0，令 α'=√2、β'=(r−a√2)/b，其中 r 为任意有理数。则 α'、β' 都无理，却有 aα'+bβ'=r。这个例子并不声称 ζ 值满足这样的关系，只说明要排除它必须用到 ζ 值的额外结构。

当前适合继续尝试的具体方向是 (3,1)、(1,1)、(−1,1)。它们都有全局正权重；(3,1) 的首项整数多项式值在这三者中较小，但仅凭一个阶数不能判定其渐近更优。任何一个新混合方向的无理性，都仍需新的算术估计；证明有限多个混合方向无理，也不能排除其他方向上的例外射线。
