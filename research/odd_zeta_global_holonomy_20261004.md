# 算术 holonomy：从单个小值预算转向函数空间维数矛盾

日期：2026-10-04。本文是原始文献核查及研究方案；没有证明新的 ζ 或 β 无理性。原件、版本和 SHA-256 见 [文献归档清单](../literature/manifest_global_20261004.json)。

## 1. 为什么这是一条实质不同的路线

Calegari–Dimitrov–Tang（CDT）证明了 **1、ζ(2)、L(2,χ₋₃) 在 Q 上线性无关**。χ₋₃ 是奇特征，因此 L(2,χ₋₃) 与 Catalan G=L(2,χ₋₄) 属于相同的相反奇偶 sector，却有不同的导子、奇异点和整模型。该定理没有包含 G。[原始论文 v2](https://arxiv.org/abs/2408.15403v2)。

经典 Apéry 路线要求整数化后的单个线性形式直接趋零。holonomy 路线研究的是：具有指定分母类型、且在同一解析域上亚纯延拓的 holonomic 函数，最多能有多少个在 Q(x) 上独立。假设某个 Apéry 极限有理，可能使原本系数含未知周期的“更好延拓解”成为有理系数解。若由此产生的实际函数秩超过算术界，就得到矛盾。这里每个函数的分母层级都参与预算。

它的技术基础包括模形式的无界分母定理、势论、算术 Hilbert–Samuel 与 Bost 的斜率方法。引入这些理论并不消除分母成本，而是把成本与可用函数秩合并计量。[CDT 无界分母论文 v4](https://arxiv.org/abs/2109.09040v4)，[holonomy 与有效逼近论文 §2](https://arxiv.org/abs/2510.04156v1)。

## 2. 实际判据需要哪些数据

最简单的启发式装配是：

1. 构造有理系数函数 A(x)、B(x)，使 B(x)−ηA(x) 在某些奇异点的坏分支抵消。
2. 在假设 η∈Q 时，确认这个新解的系数在 Q，而非另一个未控制的周期域。
3. 连同适当辅助函数，证明 Q(x)-线性独立；使用的是实际函数关系，不能只数形式符号。
4. 对所有这些函数给出兼容的分母 staircase；一个函数好，并不代表全部导数、积分或乘积免费。
5. 构造在闭单位圆盘邻域全纯的 φ:(overline D,0)→(C,0)，证明全部拉回在 D 上亚纯，并控制边界大小、φ′(0) 和分母成本。
6. 将独立函数数目与 holonomy 上界比较，获得严格的正余量。

CDT Theorem 2.1 的一个专门版本把系数分母限制为若干 lcm(1,…,⌊bn⌋) 的积。符合原文 staircase 排序、独立性、holonomicity、解析域及正分母条件时，界的形状是

\[
m\le
\frac{\iint_{\mathbb T^2}\log|\phi(z)-\phi(w)|\,d\mu(z)d\mu(w)}
{\log|\phi'(0)|-\tau(b)}.
\]

这里 τ(b) 由整个分母矩阵确定，不能以最好一行的分母代替；φ 的边界假设也不能略掉。该式仅用于解释“秩—解析容量—算术成本”的关系，引用时须连同原文全部条件。[CDT §2.1，PDF第3–4页](https://arxiv.org/pdf/2510.04156v1)。

**本文的研究推断：**现有 ζ(7) 构造可能在单个本原小值预算上失败，却仍可作为这种函数系统的部分数据。是否有价值必须检查独立函数秩与完整分母 filtration；已有固定 Gram 失败证书并没有计算这个新的量。反过来，对一个固定有限阶微分方程不停求导，不会使 Q(x)-函数秩无界，因为导数仍满足同一个有限秩系统。

## 3. Catalan 的实 / 2-adic 差别给出具体警示

CDT §5.2 的同一 Catalan 系统，在实侧有

\[
D(x)=B(x)-\frac G2A(x)-\frac{\pi^2}{16}C(x),
\]

而相应的 2-adic 周期实现是

\[
D(x)=B(x)-\frac{G_2}{2}A(x).
\]

实侧 D 在所选原点 x=0 奇异，且表达式混入额外 Tate 周期 π²C（C也有相应对数分支）。因此即使假设 G 有理，仍没有取得定理要求的“有理系数、原点正则且具有好延拓的芽”。必须同时处理基点/坏分支与Tate项，并核对完整周期矩阵或构造真正的新对象。不能把两个周期实现视作 R→Q₂ 的数字嵌入，更不能从 G₂ 无理直接推 G 无理。[原文 (5.10)–(5.11)](https://arxiv.org/html/2510.04156v1)。

这也解释为什么“更深数学”仍需要精确整格：删掉 π² 的形式动机投影，只有在能够实现成真实几何子商、比较周期和整模型后，才能作为判据输入。

## 4. 已知失败的适用范围

CDT 的 L(2,χ₋₃) 长文 §11.1 专门核对了两组既有 Catalan 逼近。它们的奇异点与分母类型尚未达到所需 holonomy 门槛。因此这些具体家族不能直接复制已成功的论证，需要新输入。这个分析没有排除其他局部系统、其他周期组合或一般 holonomy 改进。[长文 §11.1，PDF第163页起](https://arxiv.org/pdf/2408.15403v2)。

换成任意更大秩系统也不保证改进：新增积分提高分母层级，新增乘积引入未知周期的乘积，完整账本的净秩优势可能仍为负。所需命题应是一个跨权重的**秩优势存在定理**，而非“任何动机都满足相同好不等式”。

## 5. 建议的具体交付

先以已成功的 χ₋₃、权2系统校准，再进入 level 4 的权2与 level 1 的权7。每个系统只报告以下可审阅数据：

| 模块 | 数学交付 |
|---|---|
| 周期与坏分支 | 完整比较矩阵；哪个关系才导致亚纯延拓 |
| 特征与投影 | 字符、复共轭、Tate项；真实子商存在的证明 |
| 算术 | 统一 de Rham/Betti 整模型；全部坏素数；分母 staircase |
| 函数秩 | 最小微分系统或独立性证书；不能把形式坐标数当函数秩 |
| 解析 | 奇异点、单值化、φ及可验证容量界 |
| 最终余量 | 对上述同一系统应用定理；若失败，指出是哪一个输入或不等式缺失 |

若能证明对每个相反奇偶的目标，至少存在一个满足这些条件且有正余量的系统，就会得到一种真正统一的无理性方法。余量允许依赖权和导子，不必使用相同参数；目前没有从文献中取得这样的存在定理。
