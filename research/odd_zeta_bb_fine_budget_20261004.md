# Borwein–Bradley 八维自然系统的精细 CDT 算术障碍

日期：2026-10-04。本文是 [新真实周期系统报告](E:/kimi-build/zeta5/research/odd_zeta_new_period_systems_20261004.md) 的独立续篇，不修改冻结旧稿。仅研究该报告已经证明实际独立的自然八函数 `1,L₁,L₂,L₃,L₄,U,V,f_c`，变量始终为原 z。本文不将自然基的逐项结论直接推广到任意有理 gauge。

**本轮精化。** 对每个固定有理 c，f_c 的实际共同前缀分母指数恰为 7；并且自然八函数的任意固定 `n^e` / lcm 型 CDT 阶梯分配，都有 `τ♭≥201/64>log4`。后者直接约束精细分母类型，不是用前缀指数 7 代替精细成本。

## 1. 实际系数及需要分开的两种指标

沿用旧报告记号

\[
C_n=\binom{2n}{n},\quad H_{n-1}^{(4)}=\sum_{j<n}j^{-4},\quad
t_n=\frac{(-1)^{n-1}}{n^3C_n}\left(n^{-4}+5H_{n-1}^{(4)}\right),
\]

\[
f_c(z)=\sum_{n\ge0}d_nz^n,\qquad
d_n=C_n\left(c-\frac52\sum_{k=1}^nt_k\right).
\tag{1}
\]

自然低层的两系数是

\[
u_n=[z^n]U=(-1)^n\left(n^{-5}+5n^{-1}H_{n-1}^{(4)}\right),
\]

\[
v_n=[z^n]V=(-1)^n\left(n^{-6}+5n^{-2}H_{n-1}^{(4)}\right).
\tag{2}
\]

`L_j=Li_j(−z)` 的第 n 项为 `(-1)^n/n^j`。这些是同一个已认证八维系统的系数，不使用 ζ(7) 的数值或无理性。

精细类型中的 `n^e` 作用于当前系数序号 n。例如研究 n=p+1 时，它是 `(p+1)^e`，不是 p^e，也不能改写为移位的 `(n−1)^e`。

## 2. 自然目标与驱动函数的移位素数分母

固定 c∈Q，只排除 p=2、5 及 c 的分母素数。以下每个充分大奇素数 p 都适用。

中央二项式的 Lucas 同余给

\[
C_p\equiv2\pmod p,\qquad C_{p+1}\equiv4\pmod p.
\tag{3}
\]

因此二者都是 p 单位。在 t_p 中，`p^−7/C_p` 是唯一最低项，H_(p−1)^(4) 为 p 整，故

\[
v_p(t_p)=-7.
\]

对 k<p，k 与 H_(k−1)^(4) 都 p 整，而 C_k 至多有一次 p carry，所以 `v_p(t_k)≥−1`。对 k=p+1，H_p^(4) 的唯一最低项是 p^−4，k 与 C_k 是单位，故 `v_p(t_(p+1))=−4`。这些项不能抵消 t_p 的 −7 层；乘 C_(p+1) 与 5/2 都是单位。因此

\[
\boxed{v_p(d_{p+1})=-7.}
\tag{4}
\]

式 (2) 在 n=p+1 的谐波项同样具有唯一最低层 −4，其他项 p 整，给

\[
\boxed{v_p(u_{p+1})=v_p(v_{p+1})=-4.}
\tag{5}
\]

这不是对几个素数的经验拟合。关键是分母出现在与 p 互素的系数序号 p+1；任意固定 n^e 都不能清掉这一层。

## 3. 素数幂位置的更强有限结论

实际上，对每个 `q=p^a`，p 为奇素数、p≠5 且 p 不整除 c 的分母，也有

\[
\boxed{v_p(d_{q+1})=-7a,\qquad v_p(u_{q+1})=v_p(v_{q+1})=-4a.}
\tag{6}
\]

证明。C_q、C_(q+1) 的 Lucas 同余仍分别为 2、4。若 k<q，令 `b=v_p(k)≤a−1`；C_k 的 carry 在 j≤b 的层为 0，在 j>a 的层也为 0，因为 `2k<2p^a<p^(a+1)`。剩下最多 a−b 层，因此

\[
v_p(C_k)\le a-b.
\]

H_(k−1)^(4) 各项的赋值至少为 `−4(a−1)`，所以 t_k 的纯项与谐波项分别有下界

\[
-7b-(a-b)=-a-6b\ge-7a+6,
\]

\[
-3b-4(a-1)-(a-b)=-5a+4-2b\ge-7a+6.
\tag{7}
\]

t_q 的纯项为 −7a；其谐波项至少为 `−7a+4`，故仍是唯一最低层。t_(q+1) 的 H_q^(4) 由 q^−4 给唯一最低层 −4a。因为 `−4a>−7a`，式 (1) 的有限和有唯一最低项 t_q。乘单位后得到 d_(q+1) 的结论；式 (2) 直接给 U、V 的结论。

令 S 是 `{2,5}` 与 c 分母素数组成的固定集合，令 `L_N^(S)` 是 `lcm(1,…,N)` 删除 S 中全部素数因子后的正整数。对所有 N≥2，(6) 给真实有限整除关系

\[
\left(L_{N-1}^{(S)}\right)^7\mid\delta_{f_c}(N).
\tag{8}
\]

冻结旧报告已经严格证明上界 `δ_f_c(N)|2q_c L_N^7`，其中 q_c 清 c 的固定分母。素数定理给 `log L_N=N+o(N)`；删除固定素数只改变 O(logN)。合并后得到

\[
\boxed{\log\delta_{f_c}(N)=7N+o(N)\quad(c\in\mathbf Q\text{ 固定}).}
\tag{9}
\]

这里精化的是该自然尾提升族的共同前缀指数；不声称有限 δ_f_c(N) 等于 L_N^7。旧稿的 6 至 7 区间仍然成立，但本独立续篇确定了精确主指数。

## 4. 任意固定 n^e / lcm 类型必须保留七层或四层

对一个自然函数的系数，允许 CDT 精细类型

\[
a_n\Big/\left[n^e\prod_{j=1}^rL(\lfloor b_jn+c_j\rfloor)\right],
\qquad a_n\in\mathbf Z,
\tag{10}
\]

其中 e≥0 为固定整数，r、b_j≥0 和整数 offset c_j 都固定；L 为区间 lcm。允许先乘固定整数清有限初值；固定坏素数不影响以下结论。

取 n=p+1。n^e 是 p 单位。每个 endpoint 为 O(p)，对充分大 p 小于 p²，所以**每个 lcm 层至多贡献一次 p**。若 b_j<1，则 endpoint 最终小于 p，该层一次 p 也不贡献。因此 (4)、(5) 分别强制

\[
\#\{j:b_j\ge1\}\ge7\quad\text{对 }f_c,
\qquad
\#\{j:b_j\ge1\}\ge4\quad\text{对 }U,V.
\tag{11}
\]

特别是其各行和 σ 满足

\[
\boxed{\sigma_f\ge7,\qquad\sigma_U,\sigma_V\ge4,}
\tag{12}
\]

无论这些行取多大的 e。固定 offset 不能改变 (11)，而单个很大的 b 也不能代替所需的七个 p 层：当 p 趋于无穷时任何固定 b 的 endpoint 仍小于 p²。

1、L₁至L₄ 可以各用 n^j 清自身分母，不需要在此给它们正的 lcm 下界；它们的积分成本仍计入 τ♯，不会使成本为负。

## 5. CDT 允许的嵌套结构直接给 201/64

已核对 [CDT 主文 Theorem 2.5.1 / Theorem 6.0.2](https://math.berkeley.edu/~ytang/L2chi.pdf)。其每列是零前缀、再接一个固定正 b_j 的尾段；所以行和一定满足

\[
0\le\sigma_1\le\cdots\le\sigma_8.
\]

精细成本是

\[
\tau(\mathbf b;\mathbf e)=\tau^\flat(\mathbf b)+\tau^\sharp(\mathbf e),
\quad\tau^\flat=\frac1{64}\sum_{i=1}^8(2i-1)\sigma_i,
\quad\tau^\sharp\ge0.
\tag{13}
\]

不能任意重排行和并仍声称同一列结构合法。这里根本无需这种重排：任何合法表本身行和非递减，而 (12) 说明八行中至少三行的行和≥4、至少一行≥7。因此每个合法表必有

\[
\sigma_6\ge4,\quad\sigma_7\ge4,\quad\sigma_8\ge7,
\]

直接给

\[
\boxed{\tau^\flat\ge\frac{11\cdot4+13\cdot4+15\cdot7}{64}
=\frac{201}{64}=3.140625.}
\tag{14}
\]

这一界覆盖自然八函数的全部固定 e 分配、全部有限 lcm 列与允许的行排序。五个低函数行即使给予零 lcm 成本，仍不能改善此下界；τ♯ 只会再增加成本。

平坦成本的下界本身可由一个安全表达到：四个 b=1 的列自第六行开始、三个 b=1 的列只在第八行开始，行和为 `(0,0,0,0,0,4,4,7)`。取

\[
\mathbf e=(0,1,2,3,4,1,2,0)
\]

分别支付 L_j 的 n^j，以及 U、V 中的 n^−1、n^−2；其剩余谐波部分由 L_n^4 支付，f_c 由旧报告的 L_n^7 上界支付。固定 2q_c 可整体归一化。这里只说明 τ♭=201/64 是自然安全表可达到的最小平坦成本，不声称其总 τ 或真实整数评价模块已达到最优。

## 6. 解析预算及未排除的范围

真实参数 c=ζ(7) 的已证共同域是 `U₁=C∖(−∞,−1]`。若反证假设 c∈Q，系数仍是以上同一函数。标准映射 `4w/(1−w)²` 和 Schwarz 引理给任何圆盘映到 U₁、原点映到 0 的 holomorphic φ 都有 `|φ′(0)|≤4`。

因此，针对这组自然函数、原坐标与映入此已证域的模板，完整精细判据的必要正门槛满足

\[
\log|\phi'(0)|-\tau(\mathbf b;\mathbf e)
\le\log4-\frac{201}{64}<0.
\tag{15}
\]

这次已经排除自然基的 n^e / 多类型 lcm 改分配，不再只是 scalar/common-prefix 障碍。它仍不排除：任意新有理 gauge 后不同系数序号的抵消、代数覆盖、外加实际独立函数、N 依赖的整数操作、不同评价模块，或越过旧 slit 且经拉回才单值的解析模板。本报告也没有证明 U₁ 是该真值芽的最大解析延拓域。

特别地，固定微分算子 `(θ−1)^e` 会改变第 p+1 项的赋值；不能仅沿本报告这一个移位见证，断言任意有理基变换都有同样的 (4)。更宽命题需要另证整个固定-offset packet，而不能直接挪用自然基结论。
