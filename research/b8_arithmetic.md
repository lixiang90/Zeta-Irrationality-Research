## A. τ₈ 泛函及其生成函数

**定义**（论文 §3 的 b=8 类比：τ(P) = L(P⁽⁶⁾)/720，L(x^k) = B_k）：

  τ₈(x^m) = κ_m := m(m−1)(m−2)(m−3)(m−4)·B_{m−5}/720（m ≥ 5；m < 5 为 0）

**生成函数**（关键：依赖 B₁ 约定，已数值验证）：

| 约定 | F(t) = Σκ_m t^m/m! |
|---|---|
| B₁ = +1/2（经典） | t⁶/(720(e^t−1)) + t⁶/720 |
| B₁ = −1/2（论文声明） | F₀(t) = t⁶/(720(e^t−1)) |

**【构造安全性】** pullback 像 μ₇(R) = τ₈(x⁷R(−x²)) 只含奇次幂 x^{2e+7}，
其 κ 值只用偶数指标 Bernoulli 数（约定无关）。κ₆ = B₁ 从不进入构造。
（b=6 同理：只用 κ_{2e+5}，偶数指标。）

## B. 核心恒等式（全部数值验证）

1. **差分恒等式**（(3.3)-类比，B₁=+1/2）：对一切多项式 g，
   τ₈(g(x+1)−g(x)) = g⁽⁶⁾(0)/720。
   （B₁=−1/2 时退化为仅 g=x⁶ 给 1、更高次为 0——同一事实的两种说法。）
2. **分布恒等式**（(3.7)-类比的基础，B₁=−1/2）：
   Σ_{a=0}^{p−1} e^{at}F₀(pt) = p⁶F₀(t)，即多项式部分的
   τ₈(g) = p^{−6}Σ_{a=0}^{p−1}τ₈(g(a+px))。
   论文 b=6 为 p^{−4}；此处 **p^{−6}** 是 b=8 的第一个实质常数变化。
3. **极点值的分布与 Y-位移**：极点值 τ_X(1/(x−r)) = H^{(7)}_{d(r)} − X。
   平移 telescoping 给 H⁽⁷⁾ 的乘法公式：Σ_{a=0}^{p−1}H^{(7)}_{d(a+pr)}
   = p⁷H^{(7)}_{d(r)} + C_p，故 **Y = p⁷X + C_p**（b=6 为 Y = p⁵X + C_p）。
   **C_p 的赋值**：(3.5)-类比的首项 −ΣC(k+5,5)B_k(a/p)^{−k−6} 给出
   k=0 项 −p⁶Σa^{−6}。Σ_{a=1}^{p−1}a^{−6} ≡ 0 (mod p) 当 p−1∤6，即 p > 7。
   ⟹ **C_p ∈ p⁷ℤ_p（p > 7）；p = 7 时仅保证 C_p ∈ p⁶ℤ_p**（p−1=6 | 6）。
   这是 b=8 相对 b=6 的一个真实退化点（b=6 时 p=5 被 p≥7 排除，无此问题），
   p=7 落入小素数区（由 (3.12)-类比处理，不进入中区分配）。

## B2. 分布恒等式的严格推导（2026-09-24；精确验证 `b8_distribution.py`，3200 例零违规）

此前 §B.2 只有 50 位浮点截断验证（`b8_machinery.py` §3）。此处给出完整推导
并修正一个约定陷阱（plus 约定的修正项对奇多项式**不消失**）。

**命题 1（生成函数恒等式）**. 记 F₀(t) = t⁶/(720(e^t−1))（B₁=−1/2 的 EGF）。
对任意**正整数** p（不必素）：
  Σ_{a=0}^{p−1} e^{at} F₀(pt) = p⁶ F₀(t)。
证：Σ_{a=0}^{p−1} e^{at} = (e^{pt}−1)/(e^t−1)（几何和），代入
F₀(pt) = (pt)⁶/(720(e^{pt}−1)) 即得。在 ℚ⟦t⟧ 中同样成立
（e^t 常数项为 1 是单位；消去 e^{pt}−1 后两边都是形式幂级数）。∎

**命题 2（系数比较 ⟹ 多项式分布恒等式）**. 记 τ⁻(x^m) = κ⁻_m（B₁=−1/2，
κ⁻_m = κ⁺_m − [m=6]）。e^{at}F₀(pt) 的 t^m 系数为
  Σ_{j+k=m} a^j κ⁻_k p^k/(j!k!) = τ⁻((a+pX)^m)/m!，
与 p⁶F₀(t) 的系数 p⁶κ⁻_m/m! 比较，得：对一切 m ≥ 0、一切正整数 p，
  Σ_{a=0}^{p−1} τ⁻((a+pX)^m) = p⁶κ⁻_m，即 τ⁻(g) = p^{−6}Σ_a τ⁻(g(a+pX))（∀g∈ℚ[X]）。
【验证】`b8_distribution.py` §1：p = 1..40（含合数）、m = 0..40，精确分数零违规。

**命题 3（plus 约定的修正项）**. τ⁺ = τ⁻ + Δ，Δ(g) = [x⁶]g =: c6(g)。由于
c6(g(a+pX)) = p⁶Σ_{n≥6} C(n,6)a^{n−6}c_n(g)（c_n = [xⁿ]g），求和得
  τ⁺(g) = p^{−6}Σ_a τ⁺(g(a+pX)) + c6(g) − Σ_{n≥6} C(n,6)S_{n−6}(p)c_n(g)，
S_k(p) = Σ_{a=0}^{p−1} aᵏ（S₀ = p）为幂和。
【验证】`b8_distribution.py` §2：随机稠密 g、p ≤ 13，精确零违规。

**【约定陷阱·已修正】** 早先笔记推测"修正项只对 x⁶ 型有 (1−p)c6、对奇 g 消失"
——**错误**。反例：g = x⁷、p = 2 时修正 = −C(7,6)S₁(2) = −7 ≠ 0
（`b8_distribution.py` §4 登记）。原因是移位多项式 g(a+pX) 恢复了偶次项，
其 x⁶ 系数受 g 的高次奇项贡献。

**推论（构造适用版）**. 对奇 g（如 pullback 像 g = x⁷R(−x²)）：τ⁺(g) = τ⁻(g)
（c6 = 0 且奇次幂的 κ 值只用偶数指标 Bernoulli，约定无关），故
  p⁶·τ(g) = Σ_{a=0}^{p−1} τ⁻(g(a+pX))，
RHS 必须用 **minus 约定**。这是 b=8 分布步骤对接构造的正确形式
（mo271 b=6 同构：p⁵ 与 κ⁻ 约定）。
【验证】`b8_distribution.py` §3：随机奇 g（≤ 21 次）、p ≤ 13，精确零违规。

**注记（p 为任意正整数；幂和的 p-进性质）**. 命题 1–2 不需要 p 素。
素性只在后续赋值论证进入：对素数 p，S_k(p) ≡ −1 (mod p) 当 (p−1)∣k，
否则 ≡ 0 (mod p)，故修正项 Σ_{n≥6}C(n,6)S_{n−6}c_n 的 p-进分析
（连同 c6 项）归入小素数界 (3.12)-类比的损耗核算，见 §C.6。

## B3. C_p 的精确式与 p-进赋值界（2026-09-25；精确验证 `b8_cp_shift.py`，全节零违规）

分布公式的 Y-位移常数 C_p（机器 Y = p⁷X + C_p 中的平移项）此前只有
§B.3 的旧笔记断言（v_p(C_p) ≥ 7，退化素数除外）。此处给出精确式与完整赋值界。

**命题 1（Hurwitz 整数部提取恒等式）**. 对 r ≥ 1、1 ≤ a ≤ p−1（p 为任意
正整数）：
  H⁽⁷⁾_{a+pr} = ζ(7) − p^{−7} Σ_{c=1}^{p} ζ(7, r + c/p) + Σ_{v=pr+1}^{pr+a} v^{−7}。 (I)
证：乘法公式 ζ(7, a+pr+1) = p^{−7} Σ_{k=0}^{p−1} ζ(7, r+(a+1+k)/p)；
写 a+1+k = c+pε（c ∈ [1,p]，ε ∈ {0,1}，ε=1 ⟺ k ≥ p−a），用
ζ(7, y+ε) = ζ(7,y) − εy^{−7} 提取整数部得
p^{−7}[Σ_c ζ(7, r+c/p) − Σ_{c=1}^{a}(r+c/p)^{−7}]，末项即 Σ_{v=pr+1}^{pr+a}v^{−7}，
再用 H⁽⁷⁾_n = ζ(7) − ζ(7, n+1) 整理。∎
【验证】`b8_cp_shift.py` §1：把 (I) 拆成两个精确有限恒等式联立验证——
1a. H⁽⁷⁾_{a+pr} − Σ_{v=pr+1}^{pr+a}v^{−7} = H⁽⁷⁾_{pr}（整数部提取的有限内容，
    与 ζ(7) 无关）；1b. 乘法公式的有限形式
    ζ(7,pr+1) − ζ(7,pr+1+pN) = p^{−7}Σ_{c=1}^{p}[ζ(7,r+c/p) − ζ(7,r+c/p+N)]
    （LHS = Σ_{w<N}Σ_{c≤p}(pw+pr+c)^{−7}，逐项可比对）。
p = 3,5,7,11,13 × a × r × N 全组合零违规。

**命题 2（Y-位移的精确分解）**. 由 (I) 减 H⁽⁷⁾_r 的同样展开：
  p⁷H⁽⁷⁾_{a+pr} − H⁽⁷⁾_r = (p⁷−1)ζ(7) + E_a(r)，
  E_a(r) = p⁷Σ_{v=pr+1}^{pr+a}v^{−7} − Σ_{c=1}^{p−1}[ζ(7, r+c/p) − ζ(7, r+1)]。
E_a(r) = O(r^{−7})（首项两项均 ∼ const·r^{−7}，第二项中括号 ∼ Σ(c/p−1)·7v^{−8}
求和收敛）。【验证】`b8_cp_shift.py` §2 数值同阶确认。
(p⁷−1)ζ(7) 被 Y = p⁷X + C_p 的 X 部分吸收（ζ(7) = H⁽⁷⁾_∞ 作为机器参数出现，
不破坏 p-进性——对应 DirectBound 的 "harmonic indices < p²" 处理）。

**命题 3（C_p 的精确式）**. C_p 取 (3.5)-类比的 Hurwitz 渐近级数的 p-进
正则化：
  C_p = −Σ_{a=1}^{p−1} Σ_{k≥0} C(k+5,5) B_k (a/p)^{−k−6}
      = −Σ_{a=1}^{p−1} Σ_{k≥0} C(k+5,5) B_k p^{k+6} a^{−k−6}  ∈ ℤ_p。
逐项 v_p = k+6+v_p(B_k) ≥ k+5 → ∞（von Staudt），p-进收敛，且 C_p ∈ p⁶ℤ_p。
系数来源（经典大 x 渐近，DLMF 25.11.43）：
  6x⁶ζ(7, x) ∼ 1 + 3x^{−1} + Σ_{k≥1} C(2k+5,5) B_{2k} x^{−2k}，
逐项系数恒等式 6·(B_{2k}/(2k)!)·(7)_{2k−1} = C(2k+5,5)B_{2k}
【验证】`b8_cp_shift.py` §3，k = 1..11 精确零违规（奇指标 B 为零自动覆盖）。
k=0 项即 −p⁶Σ_{a=1}^{p−1}a^{−6}，与 §B.3 旧笔记的断言吻合。
形式生成元：Σ_k C(k+5,5)B_k u^k = "6u^{−6}ζ(7,1/u) − 1 − 3u"（两侧皆实发散，
p-进一侧收敛；u = (a/p)^{−1} 时即 (3.5)-类比展开，故取其 p-进正则化作为定义）。

**定理（赋值界）**. 对素数 p：
  - p > 7：v_p(C_p) = 7（k=0 项幂和 Σ_{a=1}^{p−1}a^{−6} ≡ 0 (mod p)，
