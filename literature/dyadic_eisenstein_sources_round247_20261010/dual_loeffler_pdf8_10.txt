2.1. Modular curves over C.
Theorem 2.1.1.      (1) The C-points of a smooth connected projective algebraic curve over C are
      canonically a Riemann surface; X 7→ X an .

2.2. Descending the base field.
Question. Does there exist an algebraic curve over some number field K such that we get X(Γ)C by
base extension? (a “descent” of X(Γ)C to K?)
  Let’s think a bit about what this means.
     • Clearly not all varieties over C are definable over number fields: consider the elliptic curve
                                                                                            6192
       y 2 = X 3 + X + π. This is not defined over any number field, as its j-invariant is 27π 2 +4 .
                                                                   2     3
     • Sometimes descents exist for nonobvious reasons: e.g. πY = X + X has a descent to Q, even
       though its defining equations aren’t rational, because it’s isomorphic over C to Y 2 = X 3 + X.
     • Even if a descent exists, it may not be unique: e.g. P1Q and {X 2 + Y 2 + 2Z 2 } ⊂ P1Q become
       isomorphic over C.
So we need to ask: is there a descent to a number field that means something?
    The curves – fields correspondence. For any field k, there is a bijection
    smooth connected curves/k      ↔     field extensions K/k of transcendence deg. 1 with k̄ ∩ K = k.
In particular, for X/Q a curve,
            models of X/k     ↔    subfields K of Rat(X) generating it /C and st. K ∩ k̄ = k.
This gives a promising candidate: we can try to find a good subfield of Rat(X(Γ)) (=meromorphic wt.
0 modular functions) and use this to descend to smaller fields.
