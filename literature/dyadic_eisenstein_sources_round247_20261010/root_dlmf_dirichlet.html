§25.15(i) Definitions and Basic Properties

where χ⁡(n) is a Dirichlet character (modk) (§27.8). For the principal character χ1(modk), L⁡(s,χ1) is analytic everywhere except for a simple pole at s=1 with residue ϕ⁡(k)/k, where ϕ⁡(k) is Euler’s totient function (§27.2). If χ≠χ1, then L⁡(s,χ) is an entire function of s.

§25.15(ii) Zeros

ⓘ
Keywords:

Since L⁡(s,χ)≠0 if ℜ⁡s>1, (25.15.5) shows that for a primitive character χ the only zeros of L⁡(s,χ) for ℜ⁡s<0 (the so-called trivial zeros) are as follows:

n=0,1,2,…,
