# A247 的有限官方来源选择

2026-10-10。本文件为本人所读来源的归纳记录，不是上游原文全文。

1. William Stein, *Modular Forms, A Computational Approach*, 官方作者书：
   https://wstein.org/books/modform/modform/eisenstein.html 。Equation (4)、Theorem 5.8/5.9 的完整 statement 已读所存 selected text。本轮用到常数规范、字符 parity 条件及 E(q²) 的 level oldform 模性。一般证明由该页指向 Miyake；没有重新认证 Miyake。

2. Yifan Yang, *Apéry limits and special values of L-functions*, arXiv:0709.1968v1：
   https://arxiv.org/abs/0709.1968 。本轮实际完整复读所存物理 PDF5–11 与15–16。前者包括 variation Lemma1、native normalization、Lemma3/4 的 statement/proof、Fricke/非Fricke比较；后者包括 level7 的 t,A,f 与 Theorem2，以及 cusp 方法。本文的 dyadic affine cocycle 是自行两次微分与 involution 推导，未搬用一个未核 Mellin contour。

3. Calegari–Dimitrov–Tang，官方 arXiv:2408.15403 当前 v2：
   https://arxiv.org/abs/2408.15403 。网页实际核版本2024-09-16。所存作者本物理 PDF1–5、33–35 全部选页本轮实际读完；包括 Theorem A、intro 中 Apéry 接口，以及 §2.11 simultaneous-monodromy coefficient 的真实过收敛机制。所读定理针对 χ−3。没有声称读全218页，或在该来源找到 level14 的数值定理。

4. Gun–Kandhil–Philippon，*On linear independence of Dirichlet L values*：
   https://arxiv.org/abs/2212.00366 。只读官方 abstract 与 metadata。abstract 明示 same-parity / distinct coprime moduli；不把它当成本文 opposite-parity Y 的 theorem。没有下载此 PDF，也没有引用未读 theorem。
