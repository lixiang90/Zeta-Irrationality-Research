# 长期重型研究如何跨轮次保持宏观视角

长期研究不能依赖模型记住整段聊天。可靠的工作单位是“可恢复的状态与可核查的决策”，而不是更长的压缩摘要。本协议适用于数学研究，也可用于算法、实验科学和复杂工程；具体成功标准与验证方式由项目替换。

## 1. 五种信息分工，只有一份当前状态

| 信息 | 存放位置 | 更新原则 |
| --- | --- | --- |
| 长期目的、成功标准与不可偷换的量词 | `docs/RESEARCH_GOAL.md` | 用户改目标或有证据支持转向时修订，记录原因 |
| 当前窗口、全路线状态、关键命题与复盘计数 | `research/program.json` | 单个协调者更新；是当前状态的唯一权威账 |
| 恢复用的短摘要 | `research/STATE.md` | 从状态账生成，禁止第二套手写状态 |
| 证明、实验、原件与审阅证据 | 各原有技术路径 | 保存对象规范、条件、范围和版本；稳定ID链接具体证据 |
| 为什么投入、停止或改变判断 | 状态账中的决策记录与短轮次结算 | 记录被改变的关键判断，不重复全部工作历史 |

状态账只收决策所需的关键命题和路线摘要，不尝试收录每个中间引理。长历史仍可检索；进入一个依赖时才读相应证据。这样恢复成本随当前任务增长，而不是随所有历史增长。

## 2. 恢复流程

恢复时依次回答：最终要交付什么；哪些结论可靠、在哪个范围可靠；哪些实现已停止；当前窗口试图改变什么障碍；完成首命题后怎样决定；是否到复盘时间。

本仓库执行 `python scripts/research_state.py show` 即给出这个入口。随后核工作区，读 goal 与当前任务说明，再按命题ID读必要证据。工具的 goal 提示也指向同一恢复协议。若出现矛盾，先沿证据定位纠错，不继续叠加计算或草稿。恢复不等于重新全文审计所有论文。

## 3. 开始一个研究窗口前写可裁决的任务

任务必须包含：固定对象与最终数值/系统目标；全部适用量词；已有证据与最短缺口；新机制为什么可能改变缺口；一项能决定继续或停止的首命题；所需量级和验证方式；投入上限或复盘节点。

区分三个层次的进展：

- **最终进展**：完整证明或可交付系统行为满足成功标准。
- **可行性进展**：关键准入通过、同对象严格余量变好，或更直接的有效架构出现。
- **诊断资产**：错误纠正、局部结构、范围明确的障碍和失败教训。它们可以提高选择质量，但不能自动延长同一实现窗口。

每次结算都说清属于哪一层。不能用引理数量、文件数或高精度计算替代可行性进展。反复获得局部 no-go 时，优先问是否应改变真实对象，而不是寻找下一个更细的旧参数。

## 4. 宏观复盘不是历史复述

默认4个完成研究轮一次，最迟8个；连续2轮没有改善可行准入或完整净预算则提前。组织文件、文献下载、归档和失败证书数量不重置计数。正式复盘本身也不清零；复盘后有新完成轮且连续未改善达到2即提前再评估，不能额外要求再等两个完成轮。同一已处理快照不重复触发。

复盘重新比较全路线：哪些最终接口已付；哪些障碍是下界，哪些只是上界不足；哪个新机制能作用于完整对象；预期改变多少净余量；继续它会放弃哪项更直接的工作。结论必须是投入决定，不是“尚需更多研究”。

预算进展、停滞计数与窗口期限分别核算。完整净预算改善可以终止连续停滞，却不自动延长原定窗口；到期仍未达到通过条件时，先结算并作资源选择。窗口到期可以主动触发宏观比较，不必伪造“两轮停滞”；已记账的信用也不能重复充当重开证据。

复盘还要核剩余优化的最大可能收益。若把某项费用理想地降为零，固定其余证据仍不能通过成功门槛，就不能仅因该费用继续改善而反复重开；需要改变真正限制最终出口的证据。这里判断的是当前证书组合的能力，不能从不足的上界宣布研究对象不可能。

每个停止项保存范围与重开条件。数学困难与缺少外部信息是不同问题：前者可以继续推理、反证或转向，后者才可能需要用户/外部状态改变。不能把一条路线失败写成整个目标不可能。

## 5. 协作和证据升级

主代理维护状态、整合预算和作宏观选择；证明作者写技术证据；独立审阅者检查对象、量词、关键恒等式和最终接口，至少一人主动寻找反例。避免两个代理同时修改同一状态文件。审阅标签应附实际读取范围，不能继承别人的FULL或PASS。

命题依次标为待证、条件性、有限证书、已审书面证明或形式认证；不同类型互不自动升级。发现错误时保留被替代的命题ID、来源及更正原因，标注依赖受影响的结论。自动检查能核路径、引用、状态计数与文件身份，不能自动证明数学。

## 6. 轮次结束前留下可恢复的交接

更新权威状态账，生成短STATE，核链接与计数，写明下一项具体命题及其依赖。保存证据与用户改动，再提交仓库。聊天最终答复只呈现最重要的研究结果、未完成义务和入口，不重复完整证明。

这个协议可复制到其它项目，但本次只安装在本研究仓库。它能降低上下文丢失造成的重复与漂移，不能保证解出尚未解决的研究问题。
