# 研究方向、成果与边界

本文把分散的研究记录按数学问题整理，更新至第280轮（2026年10月20日）；后续纠错优先于早期乐观判断。它是一份成果地图，不是新的证明或全球新颖性审查。当前可变任务与路线决定以[STATE](../research/STATE.md)为准。完整推导、原始计算、独审记录和文献版本仍在 `research/` 与 `literature/`。

阅读时区分三类证据：**已证结构**有书面全尺度论证；**有限证书**只覆盖声明的尺度、参数或截断；**待证接口**尚不能进入最终反证。多数后续成果尚未 Lean 形式化。本次整理没有重新全量构建 Lean，也没有重算全部历史证书。

## 1. ζ(5)：已完成的形式化基线与可迁移机制

项目接入 `mo271/Zeta5` 的完整形式化，本地绝对版桥接继承其无理性定理。历史公理检查记录只有 Lean 的标准逻辑公理。另一条按论文编号组织的忠实镜像仍含待证分析输入，不能与绝对版的完成状态混同。

真正可迁移的机制是同一构造同时满足：整数多项式、次数线性增长、目标处严格正性，以及清分母后仍有负二次指数。若目标假设为固定有理数，评价分母只产生线性指数，最终得到趋于零的正整数。正 Gram 提供非零性，局部行列式整除控制所有系数，实侧容量提供二次衰减。

**经验：**迁移到更高奇值时，必须逐项重建这三个接口。已有 ζ(5) 基线、原论文建议及上游形式化不能计作本项目对新指定值的突破。见[方法重新分析](../research/zeta5_method_research_expansion_20261004.md)与[重启审计](../research/restart_analysis.md)。

## 2. ζ(7)：Gram、端点修正与完整整数格

重启审计纠正了实验矩公式多乘一项的问题，并指出 Lean 构造参数与旧算术模块仍不一致。同参数重结算后，旧算术常数不能与新实侧常数拼接。均匀测试测度给出严格变分下界，在七个明确参数点排除了“只换比较测度就闭合现有预算”的设想。

后续保留三类成果：端点 Schur 判据与头块障碍；一个固定余类的全部整数参数优化；纯目标 Padé 的完整饱和整数核及半维范围的一般秩公式。固定余类借助整数理想、完整局部根和 CRT 凹性处理全部参数，没有高度截断。三个尺度的尾部修正确实改善同维原构造，却仍劣于各自头块。完整整数格也显著改善若干有限候选的分子高度与本原值。

**未完成：**没有一列已认证、次数线性且在无界尺度上严格非零并负二次衰减的纯 ζ(7) 整数多项式。固定余类的排除不覆盖其他余类；必要保护界不表示整个保护集为空；有限格搜索不表示全格最优。

**经验：**先寻找能改变头块或宏观内容的结构。扩大已完整关闭的参数高度不会产生收益。见[ζ(7)成果总稿](../research/zeta7_research_progress_20261004.md)及[端点头块障碍](../research/zeta7_endpoint_head_barrier_20261004.md)。

## 4. 对数矩与 Padé：非零机制已经明确，净预算尚缺

显式七重对数矩候选接入合流多重正交与标准 polylog Padé。实际端点由共轭复鞍点控制，已得到非零振幅和正的原始增长指数；因此“消去高阶矩会让裸端点趋零”的猜想失败。素数分母论证另给一个可复用引理：候选有理根在无穷互异素数处有负赋值时，固定实目标在该子列只有有限个零项，无须预设目标无理。

算术研究进一步纳入目标系数与完整 gcd，把缺口改写为真实约分根分母的缺层量。相邻三行根分母有无条件指数高度下界；一些第二层 p-adic 展开恢复了看似损失的分母层。已分类的逐项反射消去只有对数级素数重量，未控制的一般异常总和仍是核心。固定有理移位与端点 type-I 转置被证明不改变原本原指数。

另有单正测度 Markov 接口，适用于奇数 ζ、Catalan 和正组合，具有全尺度严格正余项及明确裸指数，完整整数成本尚未闭合。

**经验：**归一化误差小与本原整数形式小不同；第一层局部抵消也不等于同幅净节省。见[对数矩总稿](../research/odd_zeta_log_moment_progress_20261005.md)和[真实本原缺层](../research/odd_zeta_primitive_routes_progress_20261005.md)。

## 5. 周期与 arithmetic holonomy：有闭合推论，也有严格入口限制

利用 CDT 已知定理，项目确实推出一族五项有理点二重对数组合的无理性和四项有理线性无关，并完整分类六分点 trigamma 及相应有理对数积分组合的有理关系。这些是已有定理的具体推论，未确认全球首次性，也没有隔离其中某个单独 Li₂ 值的新无理性。

结构资产包括：真实周期投影、兼容整数 Betti 来源的商、精确坏边界、全前缀分母、实际循环秩，以及整数坐标变换下前缀分母不变而逐项精细类型可改变的证明。固定投影指标或低 de Rham 秩不能自动支付完整整数比较费用。

该方法的关键链条是：假定数值关系后，产生真实有理芽并消掉完整坏支；再为同一函数族支付独立秩、所有分母阶梯、共同合法解析叶和严格余量。普通 polylog 本来已有有理系数，减去一个假定有理的端点常数往往只改常数项，没有增益。

**经验：**先证明“关系触发解析域改善”，再投入地图与预算。见[周期成果与分类](../research/period_holonomy_progress_20261005.md)及[CDT机制](../research/period_holonomy_cdt_mechanism_20261005.md)。
