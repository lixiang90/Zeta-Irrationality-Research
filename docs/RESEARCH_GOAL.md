# 长期研究 goal 与当前阶段

更新日期：2026-10-13。用户要求建立能跨轮次恢复宏观判断的工作组织，并启动进一步研究。长期数值目标保持不变；工作组织是实现它的支持机制。

## 最终目标

在 ζ 与 Dirichlet L 特殊值研究中，取得至少一项**明确指定数值的、已有所核一手定理不直接覆盖的无理性或有理线性无关结论**，交付完整可复核证明、来源核查和必要证书。优先目标仍包括 ζ(7)、3ζ(3)+ζ(5)、新的指定 L 值或明确组合；当前首证书针对 ζ(2)±2G 的实际联合评价格。换具体数值出口须由宏观比较决定，不能为容易完成而改成已知推论或“集合中至少一个”。

成功时必须一起付清：真实数值投影/关系触发；同一对象的全部算术整性或高度；所选接口需要的实际函数秩或无界非零；同一归一化下的严格解析净余量。保存独立复核。形式化按成熟程度推进，不能以现有上游ζ(5)基线或带占位的镜像代替新数值结论。新颖性核查说明实际范围，不声称穷尽所有文献。

局部结构、费用改善、错误纠正和停止证书是阶段成果，不表示总goal完成。若指定路线失败，按保存的范围停止它，继续宏观来源比较；不重命名目标，也不把所有研究判作不可能。

## 启动时的研究基线

第262轮之前的数值新目标尚未完成。旧混合rank3载体的标准LCM、自然AP标量前缀、仅辅助次数分布与亚纯地图逃生口，均已有准确的限定障碍。对自然AP模型，费用32/27而全图λ<log3<10/9；沿所选BC接口，任何新有效费用必要小于 `(2/3)log3<20/27`。这些不是所有实际联合整数格的下界。

此goal启动时选择的首窗口是**实际联合评价格的全尺度分母结构**。要识别真实系数support、尺度依赖Frobenius关系与有限评价映射；不能再把前缀率或标量cap直接当实际评价费用。首证书须给确切整数格、真实模p秩/内容及其适用范围，说明是否有足够的宏观节省，而不是只给“更多gcd可能存在”。

首窗口的两轮授权和停止条件已登记在[任务说明](../research/joint_evaluation_charter_round263_20261013.md)。**正在执行的窗口、下一命题、剩余轮数和路线状态只以[STATE](../research/STATE.md)及其权威账为准**，本节保留启动基线，不承担第二份当前状态。app goal中的初始阶段完成后，也沿状态账的最新决策继续，不因提示仍含旧轮次而重做。

若首证书不给可望跨门槛的实际收益，或算术信用被格指数/解析尺度抵消，结束相应机制的默认投入并作宏观选择。窗口关闭后总goal仍可active，下一任务改为来源选择；不得把同一窗口改task ID、改轮次或改名续期。有限精确计算若用于发现反例/机制，先说明决策用途，最后仍要给一般证书。
